# Lexicon data

`en_words.tsv` is derived from wordfreq (CC BY-SA 4.0, Robyn Speer) and filtered with SCOWL (see ../third_party/SCOWL-LICENSE.txt). This derived database is distributed under **CC BY-SA 4.0**.

Columns: word (preferred casing), Zipf frequency x100, V = in SCOWL / F = frequent informal word.

`en_replacements.tsv`: apostrophe-less contractions and the weakest autocorrect mode that applies each. `emoji.tsv`: Unicode emoji-test.txt 15.1 (Unicode License v3), fully-qualified, no skin-tone variants.
